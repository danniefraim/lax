# Contributing to Lax

Thanks for your interest! Lax is in early development, so the best way to help
right now is to open an issue with ideas, questions or feedback.

## Ground rules

- **Privacy first.** No code may send user data off the machine. Network access
  is limited to local model servers and explicit model downloads.
- Keep changes small and focused, one thing per pull request.
- Be kind. Questions from beginners are welcome.

Build instructions will be added once the app scaffold is in place.
