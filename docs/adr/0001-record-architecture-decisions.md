# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-10

## Context

Lax is an open-source project that handles very sensitive data. Contributors and
users need to be able to understand, and question, why it is built the way it is.

## Decision

We record significant decisions as Architecture Decision Records in `docs/adr/`,
using the format in [template.md](template.md).

## Consequences

Decisions take slightly longer to make, and are much easier to understand later.
New contributors have one place to read the reasoning behind the design.
